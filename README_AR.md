# دفعات الطلاب — النسخة الاحترافية

نسخة مطورة من التطبيق تشمل:
- لوحة مالية: المتوقع، المحصل، المتبقي، ونسبة التحصيل.
- فلاتر للمتأخرين، اليوم، القريبين، ومن دفعوا هذا الشهر.
- بحث بالاسم أو الهاتف وفرز متعدد.
- صفحة تفاصيل لكل طالب وسجل دفعات كامل.
- إضافة هاتف وملاحظات وزر واتساب برسالة تذكير جاهزة.
- تسجيل دفعة سريعة وتعديل وحذف الطالب.
- حذف دفعة من السجل مع إعادة احتساب آخر دفعة.
- تصدير واستيراد نسخة احتياطية JSON.
- تصدير CSV مناسب لـ Excel.
- وضع داكن.
- OneSignal + Netlify Functions للتنبيهات الخلفية.

## تحديث الموقع
ارفع/ادفع جميع الملفات إلى جذر GitHub المرتبط بـ Netlify، بما فيها مجلد `netlify/functions`.
اترك متغيرات Netlify الموجودة:
- ONESIGNAL_APP_ID
- ONESIGNAL_REST_API_KEY

بعد الـ Commit سيعمل Netlify Deploy تلقائيًا.
