# دفعات الطلاب — نسخة التنبيهات الحقيقية في الخلفية

هذه النسخة ترسل Web Push حقيقي عبر OneSignal، لذلك يمكن أن يصل التنبيه على iPhone حتى لو كان الموقع/التطبيق مغلقًا.

## ما الذي تحتاجه مرة واحدة؟
1. موقع منشور على HTTPS (Netlify مناسب).
2. حساب OneSignal مجاني وإنشاء Web Push app بنمط Custom Code وربطه بعنوان موقعك.
3. من OneSignal انسخ:
   - App ID
   - REST API Key
4. في Netlify > Site configuration > Environment variables أضف:
   - ONESIGNAL_APP_ID
   - ONESIGNAL_REST_API_KEY
5. أعد Deploy للموقع.
6. على iPhone (iOS 16.4 أو أحدث): افتح الموقع في Safari > مشاركة > إضافة إلى الشاشة الرئيسية.
7. افتح الأيقونة من الشاشة الرئيسية واضغط «تفعيل تنبيهات الخلفية» ثم اسمح بالإشعارات.

## كيف تعمل؟
- عند إضافة/تعديل طالب، أو تسجيل دفعة جديدة، الموقع يحسب موعد الاستحقاق التالي بعد شهر تقويمي.
- يحدد موعد التنبيه حسب الاختيار: يوم الاستحقاق / قبل يوم / قبل 3 أيام.
- يرسل للخادم وقت التنبيه، والخادم يجدول Push في OneSignal الساعة 9:00 صباحًا بتوقيت الجهاز.
- عند تغيير موعد الطالب أو تسجيل دفعة جديدة، يحاول إلغاء التنبيه السابق ويجدول تنبيهًا جديدًا.
- عند حذف الطالب، يحاول إلغاء التنبيه المجدول له.

## مهم
- لا تضع REST API Key داخل index.html؛ المفتاح يجب أن يبقى في Netlify Environment Variables فقط.
- البيانات الأساسية للطلاب تبقى محفوظة محليًا على جهازك مثل النسخة السابقة.
- مع تعدد الأجهزة، كل جهاز يحصل على هوية Push خاصة به.

## النشر
هذه النسخة تحتاج Netlify Functions، لذلك لا يكفي Netlify Drop الساكن وحده. استخدم Deploy from Git (GitHub/GitLab) أو Netlify CLI حتى يتم نشر مجلد netlify/functions أيضًا.
