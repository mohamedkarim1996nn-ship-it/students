# دفعاتي — النسخة النهائية

نسخة احترافية من تطبيق إدارة دفعات الطلاب، تعمل كتطبيق ويب PWA على iPhone وتدعم OneSignal للتنبيهات الخلفية.

## أبرز الميزات
- هوية جديدة باسم **دفعاتي** وأيقونة تطبيق مخصصة.
- لوحة مالية: المتوقع، المحصل، المتبقي، ونسبة التحصيل.
- حالات واضحة: متأخر، مستحق اليوم، قريب، منتظم.
- بحث، فلترة، وفرز.
- صفحة تفاصيل وسجل دفعات لكل طالب.
- تسجيل دفعة بتاريخ تختاره وإعادة جدولة التنبيه تلقائياً.
- واتساب برسالة تذكير جاهزة.
- تقارير مختصرة وتصدير CSV.
- نسخة احتياطية واستعادة JSON.
- وضع داكن.
- شريط تنقل سفلي مناسب للآيفون.
- اختيار وقت التنبيه من الإعدادات.
- OneSignal + Netlify Functions للتنبيهات حتى والتطبيق مغلق.

## التحديث على GitHub / Netlify
ارفع **كل محتويات هذا المجلد إلى جذر Repository** المرتبط بـ Netlify واستبدل الملفات القديمة.

اترك متغيرات Netlify كما هي:
- `ONESIGNAL_APP_ID`
- `ONESIGNAL_REST_API_KEY`

بعد Commit جديد سيعمل Netlify Deploy تلقائياً.

## الحفاظ على البيانات
النسخة تستخدم نفس مفتاح التخزين السابق `studentPayments.v1`، لذلك بيانات الطلاب الحالية على نفس الجهاز/المتصفح تستمر بعد التحديث.
